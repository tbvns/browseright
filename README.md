# Usage

### Prerequisites
*   Node.js (v18 or higher recommended)
*   npm or yarn

### Installation Steps

1.  **Clone the repository**
    ```bash
    git clone https://github.com/tbvns/browseright.git
    cd browseright
    ```

2.  **Install dependencies**
    ```bash
    npm install
    npx playwright install
    ```

3.  **Run the server**
    ```bash
    node ./main.js
    ```
